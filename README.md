## 📥 Installation

To run this project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/satyam-umrao/Golang.git
   ```
2. **Navigate to the project folder**
   ```bash
   cd Golang
   ```

3. **Run Go programs**
   ```bash 
   go run <filename>.go
   ```
Make sure you have Go installed (version 1.18+ recommended).

## ▶️ Usage

Each .go file inside the repository highlights a specific Go concept. You can:

    ✔ Explore the code
    ✔ Modify the examples
    ✔ Compile and execute with go run

Example:
    ```
    go run 1-Syntax.go
    ```
